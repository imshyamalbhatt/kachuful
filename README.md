# Kachuful

A scorekeeper for Kachuful (Judgement), so the table doesn't need a notepad. One phone for the whole group.

- Trump rotates every round: Kali ♠, Chukat ♦, Fuli ♣, Laal ♥ (Ka-Chu-Fu-L).
- The deal passes clockwise automatically.
- Bids are entered from the dealer's left, and the dealer can't bid the number that makes total bids equal the tricks.
- Tricks won are entered after play, and points are worked out from the scoring rule chosen at setup.
- The scoreboard looks like the notepad sheet, and any past round can be corrected.
